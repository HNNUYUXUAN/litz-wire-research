# 学术成稿与研究工具体验改进计划

## 目标与确认节点

以私有候选版本 `29bfaef` 为基线，围绕学术阅读、成果获取和轻量复现完善交付。第一阶段提供一份中文合并论文样稿；用户确认正文、图文组织与版式后，再把同一结构应用到双语论文、报告和章节稿。现有正式成稿作为版本基线保留。

本阶段的产物为中文合并论文的 Markdown、LaTeX、单栏 PDF 和 Notebook，配套阅读检查记录；同时完善仓库入口、路线发现和实际工具诊断。样稿包含五章正文与三项补充材料，复用已有图件与数值来源。

## 一、中文论文样稿

1. **论证主线。** 引言提出局部趋肤校准、共同端约束和有限长度纵向模型三个问题；方法给出物理量、方程与可比较条件；结果围绕观测量解释；讨论分别回答三个问题并界定结论范围。
2. **内容取舍。** 正文保留影响结论的工况、数值结果和不确定性。运行身份、恢复方式和诊断过程进入补充资料。几何、RT0 外场、A–φ 和 Ansys 的状态依原始证据表述。
3. **图文关系。** 图和公式紧邻首次解释的位置，正文逐图指出需要观察的趋势。图题居中，说明另段左对齐，面板字母位于图上方。沿用独立图 88.9 mm、组图 182 mm。
4. **阅读版式。** 中文宋体、西文 Times New Roman，统一标题层次、段落与公式间距，控制浮动体顺序和页面留白。文中数字使用与证据精度相称的显示位数，完整数值留在数据层。
5. **确认材料。** 提供全文及代表页面，重点确认研究主线、语言密度、图文节奏、图注和有效位数。记录尚待确认的编辑选择。

## 二、仓库阅读入口

README 优先呈现四份合并稿和适用读者；章节按所属稿件分组。GitHub 上的链接指向实际受 Git 管理的内容；附件通过真实 Release 入口和下载命令获取。阅读指南给出恢复后的 PDF、Notebook 和图件位置，并说明对应软件。

在样稿确认后的候选版本中，四份合并 PDF 分别作为可直接下载的附件；Notebook 和完整图件保留按需获取入口。GitHub 正文的轻量预览图与完整出版图件采用共同的图件身份，并验证其显示范围。读者从 README 到合并 PDF 的路径作为独立验收项目。

验收按新读者操作：从 README 选择中文论文，访问正文，恢复所需附件，打开完整图文，定位一张图的数值来源。记录实际命令、耗时、文件位置和失败诊断。

## 三、工具与开发交接

统一呈现各路线的模型身份、运行入口、依赖、数据集和支持状态。环境检查区分工具发现、版本探针和模型执行条件；帮助输出使用户能选择可用路径。文档给出一个完整的轻量运行及结果解释示例。

在含空格路径的独立目录验证安装/调用、环境诊断、解析运行、结果读取及必要的缺失依赖诊断。大型计算的状态通过既有证据解释；本轮运行范围为解析、小规模工具检查和文档后处理。

## 四、阶段与验收

| 阶段 | 交付 | 通过依据 |
| --- | --- | --- |
| A 样稿与入口 | 中文合并样稿、阅读指南、工具改善 | 全文实际阅读；每页渲染检查；附件读取与解析示例实测 |
| B 用户确认 | 语言、结构、图文与字号意见 | 用户对样稿的具体反馈与确认 |
| C 全格式推广 | 双语报告、论文、章节及全部格式 | 段落对应、引用编号、章节截取、逐页 PDF 与 Notebook 阅读检查 |
| D 候选版本交接 | 成稿包、私有候选仓库与恢复记录 | 新目录恢复，使用路径复现，文件来源与数值核对 |

本阶段通过技术验证后交付样稿供确认；全格式推广在确认后执行。源文件、数据身份与验证结论分别保存。改稿过程中持续报告实际结果。

## 本阶段实施记录

- 中文样稿重排公式、图件与定量解释，独立图件可在单栏 PDF 中并排阅读，各图保留自身编号与图注。
- PEEC 敏感性图配套编号表按同一冻结 CSV 生成；图、表统一使用百分数表示相对变化。
- 阅读入口优先列出四份合并稿；完整图文恢复通过独立目录实测。当前 GitHub 正文中的出版图件仍由附件提供，轻量网页预览在候选版推广阶段完成。
- 工具提供模型清单、运行预检及分层环境诊断；基础虚拟环境、含空格目录、解析运行和附件获取均有实际执行记录。

## 资源与科学约束

运行限定八个逻辑处理器、24 GiB 任务内存、8 GiB 系统空闲内存。数值证据、物理约定和原始结果保持来源可追溯。涉及正文结论的变更均核对冻结数据；源码与正文共同表达当前设计。
