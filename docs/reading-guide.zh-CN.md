# 阅读与首次运行

[English](reading-guide.md) · [首页](../README.zh-CN.md)

从[完整稿件索引](../publications/README.zh-CN.md)选择完整报告、自动化方法论文或 Litz 物理论文。每部作品提供中英文 Markdown、Wolfram Notebook 和三种 PDF 版式。Markdown 便于快速检索，PDF 展示最终排版，Notebook 提供原生公式与可旋转三维图。

本轮本地稿件位于 `outputs/publication_review_20261015_03/`，Notebook 位于 `notebooks/publication/publication_review_20261015_03/`；独立源码包和校验清单随本地交付提供。历史 `academic-editions` 数据集保留原稿身份，当前稿件入口以索引为准。

首次计算可安装项目并执行 `litz-research doctor`、`litz-research models`，再运行 `litz-research run analytic --case tutorial`。需要其他求解器时，先阅读对应模型与适配说明。大型研究使用明确的 campaign 入口。
