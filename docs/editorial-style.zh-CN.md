# 学术成稿规范

[English](editorial-style.md)

六份双语 LaTeX 主稿构成完整研究报告、自动化方法论文和物理建模论文。段落 ID、文献键和图件身份连接原始科研证据与生成的 Markdown 阅读稿。

中文使用宋体，西文使用 Times New Roman。独立图以 88.9 mm 设计，已校准的场图和曲线面板采用 252 × 198 pt 画布。组图保留各面板身份，分图字母位于面板上方。图题标明观测量，说明性图注交代模型条件、采样方式及解释范围。

完整报告采用单栏 A4 页面，两篇论文采用 IEEEtran 期刊版式及其页面、标题、作者栏和图注规范。图宽适应实际栏宽或页面宽度。PDF 作为编译与逐页检查的临时产物。

全部编译页面均需渲染并检查，回执将页面图像绑定到 PDF 与源码哈希。科学图保留记录数据或保存场的身份；概念插图用于仓库导读，并保留生成记录。

构建记录绑定源码、量值、面板导出及产物哈希。输入清单改变时使用新的构建身份。构建及阅读入口见[稿件指南](editions.zh-CN.md)。
