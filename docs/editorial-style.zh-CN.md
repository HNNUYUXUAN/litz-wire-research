# 学术成稿规范

[English](editorial-style.md)

保留的样稿 `publication_20261013_paper_sample_09` 确立了本项目的科学论述、公式、图件和图注组织方式。原 Notebook 及验收记录保留独立哈希和运行身份。当前完整研究报告、自动化方法论文和物理建模论文采用这一成稿范式。

中文使用宋体，西文使用 Times New Roman。独立图以 88.9 mm 设计，已校准的场图和曲线面板采用 252 × 198 pt 画布。组图保留各面板身份，分图字母位于面板上方。图题标明观测量，说明性图注交代模型条件、采样方式及解释范围。

通用单栏 PDF 使用 A4 及既定阅读版式。IEEE 期刊和会议 PDF 分别使用对应的 IEEEtran 文档类选项，以及类定义的页面、标题、作者栏和图注规范。图宽适应实际栏宽或页面宽度。全部 PDF 由 LaTeX 编译，三种版式共享科学内容与引用编号。

原生 Wolfram Notebook 保留排版公式、表格和 Graphics3D。前端验收包括打开、保存、重开、全部单元渲染，以及改变视角后与原几何的核对。科学图由记录的数据或保存场重绘；概念插图用于仓库导读，并保留生成记录。

构建记录绑定源码、量值、面板导出及产物哈希。输入清单改变时使用新的构建身份。构建及阅读入口见[稿件指南](editions.zh-CN.md)。
