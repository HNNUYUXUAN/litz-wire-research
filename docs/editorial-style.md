# Scholarly presentation

[简体中文](editorial-style.zh-CN.md)

Six bilingual LaTeX masters define a comprehensive report, an automation-method paper and a physical-modeling paper. Paragraph IDs, citation keys and figure identities connect them to the retained scientific evidence and generated Markdown readings.

Chinese prose uses SimSun; Latin text uses Times New Roman. Independent figures are designed at 88.9 mm, with a 252 × 198 pt canvas for the calibrated field and curve panels. Composite figures preserve each panel's identity and place panel letters above the panels. Figure titles identify the observable; explanatory captions state model conditions, sampling and interpretation.

The report uses single-column A4 pages. Both papers use IEEEtran journal page geometry, headings, author blocks and captions. Figure widths adapt to the available column or page width. PDFs are temporary compilation and page-review artifacts.

Every compiled page is rendered and reviewed. The receipt binds page images to the compiled PDF and source hashes. Scientific plots retain their recorded data or saved-field identities; conceptual illustrations accompany the repository overview with their generation records.

The build binds source files, quantities, panel exports and output hashes. A new build identity is required when the input manifest changes. The [publication guide](editions.md) gives build and reading entry points.
