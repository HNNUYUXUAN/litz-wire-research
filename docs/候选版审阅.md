# 候选版审阅

`v1.0.0-rc.1` 为 Litz Wire Research 的私有候选版，采用独立 Git 历史，科研来源为封存提交 `7f98a4092654125597bb843f7ee0e6a586041c7a`。

从[中文说明](../README.zh-CN.md)、[学术文件目录](editions.md)、[验收标准](../tests/ACCEPTANCE.md)和[来源清单](../provenance/candidate_files.json)进入材料。使用 `litz-research data list` 浏览数据集，使用 `data fetch <dataset>` 获取所选路线及依赖。

候选材料共有 13 组数据、31,950 个文件身份、8,953 个唯一内容对象。压缩后为 65 片，合计 7,605,595,016 字节，每片最多 128 MiB。原始科研内容与元数据派生副本分别记录来源和发布哈希。

[验收记录](../provenance/validation/)覆盖 Python 与 Wolfram 解析回归、新虚拟环境安装、完整数据恢复、含空格路径迁移和轻量重绘。104 份 PDF 已实际编译并渲染全部 411 页；52 份 Notebook 已完成前端打开、保存、回读和渲染，原生三维图完成视角保存回读。与已验收成稿比较后，对有变化的 16 个 PDF 页面及 18 个 Notebook 渲染块完成了逐件检查。

审阅重点为研究范围、论证强度、署名与许可、第三方题录、命令行和下载体验。三维诊断、Ansys、RT0、纵向 PEEC 与实际换位研究状态见正文讨论和诊断附录。公开可见性与首版封存由后续发布阶段处理。
