# v1.0.0 evidence and continuation

This release delivers an auditable agent-driven research workflow with Litz calibration cases. Read the [six bilingual manuscripts](../publications/README.md), [machine-readable scientific outcomes](../provenance/convergence/scientific-summary.json), and [detailed Chinese research handoff](convergence-next-steps.zh-CN.md).

The manufactured solution passes. At 9,108 nodes the cylinder J error is about 0.877%, while true φ and gauge fail their thresholds. Replacing the analytical end trace with a two-dimensional discrete trace does not resolve the failure. Preserve the fields and inspect equation-block, boundary and integrated gauge residuals next.

The first 50 μm Maxwell mesh has 1,694 elements. Twelve linked-mesh node coordinates change by approximately 10⁻¹⁸; disabling initial-mesh fallback does not remove the change. Exact mesh identity therefore fails. Further mesh, boundary and cross-solver campaigns are gated terminal outcomes. Historical single-mesh agreement remains scoped to that case.

The [fixed upstream reviews](../provenance/convergence/upstream-review.json) distinguish 2.5D transposition, ideal-transposition homogenization, axisymmetric magnetics and three-dimensional voxel PEEC. Existing bibliography keys REPO1–REPO4 and their licenses remain in [source records](../references/sources.json). No upstream implementation was incorporated in this campaign. PyPEEC is a candidate for a small cylinder and seven-strand validation, with voxel error and resource measurements required before scaling.

Continue using SI, exp(+jωt), RMS, copper 58 MS/m at 20 °C and explicit return boundaries. Preserve common-terminal voltage, complex strand currents, actual arc length, absolute Rac, Rac/Rdc and power. Final design studies require at least 5 mm² nominal copper area, a traditional multilevel Litz baseline and improvements exceeding numerical uncertainty. Thermal and experimental validation require separate protocols.

The shared task interface records execution and physical acceptance separately. Freeze source/input hashes before execution; retain failed attempts. Use 8 logical processors, 24 GiB task memory and 8 GiB system reserve; Maxwell uses at most 4 cores with serial solves.
