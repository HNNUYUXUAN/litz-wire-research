# Reading and first run

[简体中文](reading-guide.zh-CN.md) · [Home](../README.md)

Choose the complete report, automation methods paper or Litz physics paper in the [publication index](../publications/README.md). Each work has Chinese and English Markdown, a Wolfram Notebook and three PDF layouts. Markdown supports quick searches, PDF shows the final typesetting, and Notebook provides native equations and rotatable three-dimensional graphics.

The current local manuscripts are under `outputs/publication_review_20261015_03/`, with Notebooks under `notebooks/publication/publication_review_20261015_03/`. Independent sources and checksums accompany the local delivery. The historical `academic-editions` dataset preserves the original editions; use the index for the current manuscripts.

For a first calculation, install the project and run `litz-research doctor`, `litz-research models`, then `litz-research run analytic --case tutorial`. Read the selected model and adapter guides before using additional solvers. Larger studies have explicit campaign entry points.
