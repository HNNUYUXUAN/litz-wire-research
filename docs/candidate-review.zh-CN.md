# 审阅研究稿件

[English](candidate-review.md)

从[学术文件目录](../publications/README.zh-CN.md)进入，按目的选择完整稿件：PDF 用于阅读版面，Notebook 用于原生图形，Markdown 用于正文比较，LaTeX 用于排版与复用。

比较量值前核对模型假设和观测量，沿图件来源及引用 key 查阅方法、实现、测试和保存运行。二维 Maxwell MCP 案例与三维诊断案例具有不同范围；跨求解器一致性应结合敏感性证据解释。

文档验收记录包含编译、字体嵌入、逐页渲染、Notebook 前端回读及三维视角检查。用交付清单核对文件哈希；源码修改和本地交付身份随包记录。
