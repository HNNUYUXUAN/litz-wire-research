# 自动化研究案例复现

六个[实际案例](verification.json)连接任务模板、可见工具事件、保存源码、求解文件和物理验收。完整附件通过 `litz-research data fetch automation-rc2` 恢复；脱敏副本保留 JSON 全部数值与结构位置。

按[逐步命令](README.md)执行 Wolfram 建模、独立测试、Notebook 写入回读；Ansys 在第一终端启动所属 Student gRPC 会话，在第二终端读取端口并通过 MCP 建模求解，结束时写入 stop_session。源束与回流采用两个电压基工况求出端口约束，再实际求解 20 A RMS 工况。

七股比较按 42 边形导体、材料、RMS、轴向长度、回流与外域对齐。复电流和 Rac 的观测差异分别为约 0.01068% 与 0.001328%；单遍 Maxwell 网格未完成收敛研究。频率扩展保留真实代码差异、积分、直流极限和原工况回归。

失败诊断案例保留实际 `1000mm` 单位转换错误、API 文本响应、修复差异及新运行。A–φ 案例复算原保存场导数，继续保留电势与规范验收失败。每次使用新运行号；超时后先查询所属任务，避免重复求解。记录包含可见任务与工具事件，不要求模型内部推理。
