# Standalone LaTeX templates

Each language includes single, ieee-journal and ieee-conference templates. Compile with XeLaTeX: run `latexmk -xelatex single.tex` in the chosen language directory. SimSun and Times New Roman are required. Replace the author and institution fields. The example uses SI units and a reference from the canonical library.
