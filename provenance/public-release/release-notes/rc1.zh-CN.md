# Litz Wire Research v1.0.0-rc.1 — 历史研究证据

本 Release 保留原研究源码与证据，既有标签继续指向 [`29bfaef3cb4e4f0016b4567edc501f34c50542d7`](https://github.com/HNNUYUXUAN/litz-wire-research/commit/29bfaef3cb4e4f0016b4567edc501f34c50542d7)。

当前[数据目录](https://github.com/HNNUYUXUAN/litz-wire-research/blob/main/data/catalog.json)从本 Release 选取 13 个数据集、65 个归档分片，覆盖解析校准、二维 FEM、共同端电压场路、几何、PEEC、RT0、A–φ 诊断、Ansys 与 GPU 记录、成稿输入、历史稿件、共享对象及研究记录。清单保留原路径、字节数、哈希和来源版本身份。

[归档稿件索引](https://github.com/HNNUYUXUAN/litz-wire-research/blob/main/provenance/editorial/archive/current-edition-rc1.json)标识历史稿件集 `publication_rc1_20261007_01`，共 52 个文档条目，每项包含一个 Notebook 和两种 PDF 版式，涵盖当时的完整稿与章节稿。当前六份完整稿件、十八份 PDF 和六份 Notebook 由[出版索引](https://github.com/HNNUYUXUAN/litz-wire-research/blob/main/publications/README.zh-CN.md)统一导航，并通过 [rc.2](https://github.com/HNNUYUXUAN/litz-wire-research/releases/tag/v1.0.0-rc.2) 分发。

请使用 [rc.3](https://github.com/HNNUYUXUAN/litz-wire-research/releases/tag/v1.0.0-rc.3) 的维护源码进行免凭据按需下载及当前源码检查。[数据指南](https://github.com/HNNUYUXUAN/litz-wire-research/blob/main/docs/datasets.zh-CN.md)中的目录指向本 Release 保留的附件；[公开分发记录](https://github.com/HNNUYUXUAN/litz-wire-research/blob/main/docs/open-source-readiness.zh-CN.md)记录公开访问和下载核验结果。

科学结果继续采用原记录中的模型、激励、网格与验收条件。保存的三维 A–φ 圆柱诊断包含未通过的标量势与规范检查。空间细化结果按对应的外场或输运算例及其已记录网格序列解释。公开这些证据时保留逐次运行的原始状态与验收记录。
